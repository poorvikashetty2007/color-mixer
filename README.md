# Color Mixer Challenge 🎨

A game that tests your eyes. Match the target color using the Red, Green and Blue sliders.

🎮 **Play here:** https://poorvikashetty2007.github.io/color-mixer/

## How to play
1. Look at the target color.
2. Move the RGB sliders to match it.
3. Click Check to score up to 100 points per round.
4. Finish 5 rounds for a maximum score of 500.

HTML, CSS and JavaScript
